# Simple To-Do List (React)

A lightweight React to-do app with localStorage persistence, accessible UI, and a clean light theme.

Features:
- Add, toggle complete, edit inline (Enter/Escape), and delete tasks
- LocalStorage persistence across reloads
- Accessible labels, aria-live task count, focus styles
- Modern light theme using #3b82f6 primary, #06b6d4 accent, #EF4444 error

Scripts:
- npm start
- npm test
- npm run build
